A NOTE ON SECURITY

Random should mean
random.

Unseeded IDs use cryptographic randomness from Node.js or Web Crypto. If a secure source isn't available, Snapid throws rather than silently falling back to weak randomness.

Seeded generation is deterministic by design. It is useful for tests and repeatable data, but it is not cryptographically secure.
